# Smart BMI & Wellness Calculator

A health and nutrition web application designed to help users calculate their BMI, monitor wellness, and explore healthy food information.

## 🌐 Live Website
[Visit Smart BMI & Wellness Calculator](https://smsrabon.github.io/smart-bmi-calculator/)

## ✨ Features
- BMI Calculator
- BMI Category and Ideal Weight
- Daily Calorie Estimation
- Water Intake Tracker
- Activity Tracker
- Healthy Food Database (58 Foods)
- Nutrition Information
- Diet and Exercise Plans
- BMI History and Comparison
- Health Recommendations
- English, Bangla, and Hindi Language Support
- Light and Dark Themes

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- SVG
- Browser LocalStorage

## 📱 Responsive Web Application
The application can be accessed through desktop and mobile browsers.
